    Why this matters
    
      
    AI agents get real AWS credentials to look up orders or read files. A hidden instruction in a web page or email can turn those credentials against you. The agent's IAM role decides how much damage that does.
    
    
    
    
    
      
    What ABR checks
    
      
    77 risky actions across data access, exfiltration, privilege escalation, deletion and turning off logging. It also checks 14 known IAM escalation paths, wildcard permissions, and the lethal trifecta: untrusted input, private data and a way out in one agent.
    
    
    
    
    
      
    Limits
    
      
    ABR reads identity policies only. Permission boundaries and SCPs can only remove access, but resource policies like S3 bucket policies can add it, and ABR doesn't see those. The same engine runs as a command line tool for CI.
